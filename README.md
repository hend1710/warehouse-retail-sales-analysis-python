# Warehouse & Retail Sales Analysis using Python

## Project Overview

This project analyzes warehouse and retail sales data to uncover sales trends, product performance, inventory movement patterns, and business insights that support data-driven decision-making.

## Dataset Information

The dataset contains:

* Monthly sales records
* Warehouse sales
* Retail sales
* Retail transfers
* Product categories
* Product descriptions
* Supplier information

## Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Project Workflow

### 1. Data Cleaning

* Checked missing values
* Validated data types
* Removed inconsistencies

### 2. Exploratory Data Analysis (EDA)

#### Sales Analysis

* Monthly Sales Trends
* Warehouse vs Retail Performance
* Top Selling Products
* Sales by Item Type

#### Product Analysis

* Product Sales Distribution
* Pareto Analysis (80/20 Rule)

#### Relationship Analysis

* Correlation Heatmap
* Retail Transfers Impact Analysis

### KPIs

* Total Retail Sales
* Total Warehouse Sales
* Number of Suppliers
* Number of Products
* Monthly Performance Metrics

## Key Insights

* A small percentage of products contributes to the majority of total sales.
* Beer products generate the highest sales volume.
* Sales distribution is highly concentrated among top-performing products.
* Warehouse and retail sales show different performance patterns.
* Correlation analysis reveals relationships between inventory movement and sales activity.

## Business Value

This analysis supports:

* Inventory Optimization
* Product Prioritization
* Demand Forecasting
* Sales Performance Monitoring
* Data-Driven Decision Making
